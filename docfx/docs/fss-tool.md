# fss-tool

`fss-tool` is a desktop GUI tool for previewing FontStashSharp text rendering. It renders rich text live with the MonoGame backend, including Signed Distance Field (SDF) shadow and stroke effects, so you can tune font rasterization and effect settings interactively before using them in your own application.

## Installation

```bash
dotnet tool install --global fss-tool
```

## Updating

```bash
dotnet tool update --global fss-tool
```

> [!NOTE]
> The package is not available on NuGet yet; it will be published there soon.

## Running

```bash
fss-tool
```
