# fss-tool

`fss-tool` is a desktop GUI tool for previewing FontStashSharp text rendering. It renders [Rich Text](rich-text.md) live with the MonoGame backend, including Signed Distance Field (SDF) shadow and stroke effects, so you can tune font rasterization and effect settings interactively before using them in your own application.

![fss-tool screenshot](~/images/fss-tool.png)

## Installation

```bash
dotnet tool install --global fss-tool
```

## Updating

```bash
dotnet tool update --global fss-tool
```

## Running

```bash
fss-tool
```
